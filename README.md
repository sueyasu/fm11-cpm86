# CP/M-86 v1.1 for Fujitsu FM-11

富士通FM-11向けのCP/M-86 v1.1移植です。2D／2HDの起動用FDイメージおよびHDDイメージを、リポジトリ内のソースと外部に用意したCP/M-86 CCP/BDOSコアから生成できます。詳しい手順は [BUILD.md](BUILD.md) を参照してください。

## 動作環境

8088 CPUカードを搭載したFM-11（NEC V20への換装にも対応）を対象としています。RAMは128 KiB～1 MiBに対応し、搭載量に応じてTPAを設定します。ディスクキャッシュ用に16 KiBのRAMを使用します。

2D FDD、2HD FDDおよびMDC接続のHDDに対応しています。ドライブ文字は起動メディアによらず次のように固定されています。

| ドライブ | 接続先 |
|---|---|
| A:～D: | 2D FDD 0～3 |
| E:～H: | 2HD FDD 0～3 |
| I: | HDD 1台（ディスク全体） |

2D FDD 0から起動した場合はA:、2HD FDD 0から起動した場合はE:、HDDから起動した場合はI:が初期カレントドライブになります。

HDDはM2230B、M2231B、M2232B、M2233B、M2234B、M2235B、M2241B、M2242B、M2243Bに対応します。区画管理は行わず、HDD全体をCP/M用として利用します。HDDからの起動には本移植用の8088ブートROMを使用できます。

[FM-11エミュレータ](https://github.com/sueyasu/fm11-emulator)での利用を想定した起動手順をBUILD.mdに記載しています。実機の全構成での動作は未確認です。

## コンソール

標準ではFM-11のキーボードと画面を使用します。RS-232C（USART0）に接続したシリアル端末でも利用できます。

CP/M-86のSTATコマンドでコンソールを切り替えられます。

```
STAT CON:=CRT:
STAT CON:=TTY:
STAT CON:=UC1:
```

CRT:はローカルコンソール、TTY:はシリアル端末、UC1:は両方からの入力を受け付け、両方に出力します。UC1:では入力文字が混在することがあります。BAT:はTTY:と同じ動作になります。LIST出力、PUNCH出力はUSART0を使用し、READER入力はCON入力と同じです。

ローカル画面は80桁×25行で、ANSI/VT100の基本的なカーソル移動、画面・行消去、前景色、文字装飾などに対応しています。カーソルキーはANSI形式のエスケープシーケンスを返します。シリアル出力は変換せずそのまま送信します。

## 利用上の注意

処理高速化のため、ライトバック方式のディスクキャッシュを使用しています。電源を切ったりエミュレータを終了したりする前には、CCPのプロンプトでCtrl-Cを入力し、再度プロンプトが表示されるまで待つようにしてください（ウォームブート時に全キャッシュを書き戻します）。

ディスクを交換する場合は、**交換前にCtrl-Cを入力して書き戻しを完了し、交換後にもCtrl-Cを入力してBDOSのディスク管理情報を更新してください。** 交換後のCtrl-Cを実行するまでは、新しいディスクへのアクセスを避けてください。

ウォームブート時にディスクキャッシュの書き戻しに失敗した場合は、`WBOOT: disk cache write-back failed. System halted.` と表示してシステムが停止します。この場合、再起動によってキャッシュ内の未書き戻しデータは失われます。また、ディスクの一部だけが更新されている可能性があるため、再起動後はディスクの内容を確認してください。

## FORMAT.CMD

FDおよびHDDのフォーマット用コマンドです。

```
FORMAT B:
```

のようにオプションなしで実行すると、CP/M用のデータディスクとして初期化します。A:～D:は2D、E:～H:は2HDとしてフォーマットします。

CP/Mを起動可能なFDを作成する場合には、/Sオプションを指定します。

```
FORMAT B: /S
```

/Lオプションを指定するとFDの低レベルフォーマットのみを実施します。

HDDを初期化する場合は次のように指定します。

```
FORMAT I:
FORMAT HDD /S
```

I:とHDDは同じ対象です。オプションなしではHDD全体をCP/M用として論理フォーマットし、/Sを指定すると起動用IPLとシステムも書き込みます。HDDの物理フォーマット（/L）には対応していません。

/Sを使用する場合は、起動可能なシステムが入っているA:、E:またはI:をカレントドライブにしてください。そこからシステムを読み出して対象ディスクに書き込みます。

**FORMATを実行すると対象ディスク上の既存ファイルは失われます。** 実行前に対象ドライブを確認し、必要なデータのバックアップを取ってください。

FORMAT.CMDの作成手順は [command/README.md](command/README.md) を参照してください。

## diskdefs

cpmtoolsでFDのRAWイメージを操作するためのディスク定義ファイル（[diskdefs](diskdefs)）を用意しています。2Dおよび2HD用の設定を記述しています。D88ファイルには直接使用できません。
